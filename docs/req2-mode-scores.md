# R2-14 모드별 기록 정책과 검증

이 작업은 `chore/req2-existing-completion`의 마지막 커밋 `d30cba3` 위에서 진행한다. R2-09·11·12의 수용 검사와 기존 독립 회귀 55개를 함께 유지하며, R2-14의 모드별 저장·조회·표시를 완성한다. 원본 R2-06은 이전 작업 이력으로 보존한다.

## 저장과 호환

| 파일 형식 | 해석 | 조회 위치 |
|---|---|---|
| `이름:점수` | 이전 기록, 난이도·모드 미상 | All |
| `이름:점수:난이도` | 난이도만 있는 이전 기록, 모드 미상 | All |
| `이름:점수:난이도:모드` | 새 게임 기록, Easy/Normal/Hard 및 Classic/Item | All 및 해당 모드 |

- 새 게임은 시작할 때 확정한 난이도와 모드를 종료·이름 입력·저장까지 유지한다. 이후 설정이 바뀌어도 진행 중인 게임의 기록 메타데이터는 바뀌지 않는다.
- 기존 파일을 이관하거나 다시 쓰지 않고 새 기록을 덧붙인다. 마지막 줄바꿈이 없으면 구분 줄바꿈을 보충한다. 기존 2·3인자 저장 API의 형식과 기존 Score 생성자도 유지한다.
- 모드를 알 수 없는 기록을 Classic이나 Item으로 추정하지 않는다. All에서 기존 내용 그대로 조회하며 모드별 순위 진입 판정에는 포함하지 않는다.
- 기존 파서가 허용한 숫자 경계·빈 이름·공백 처리와 끝 구분자 호환을 유지한다. 예를 들어 `Tail:20::`는 이전처럼 난이도·모드 미상 기록이다. 유효한 4필드 기록에는 알려진 난이도와 모드가 모두 필요하다. 잘못된 메타데이터나 추가 비어 있지 않은 필드는 건너뛰고 다음 정상 기록을 읽는다. 읽기가 파일 바이트를 변경하지 않는다.
- 기록 파일과 데이터 경로는 기존 `tetris_score.txt`를 유지한다. 설정 화면의 Reset Scoreboard는 모드·난이도와 관계없이 전체 기록을 지운다.

## 순위와 화면

- 시작 메뉴의 SCORE는 All 목록을 연다. All은 기존 기록과 새 기록을 함께 표시한다. Classic과 Item 버튼 또는 좌우 방향키로 표시 모드를 전환한다. Enter는 시작 메뉴로 돌아간다.
- 각 목록은 점수 내림차순 상위 10개를 표시하고, 부족한 순위에는 기존 빈 칸 표시를 사용한다. 동점은 파일에 먼저 저장된 기록이 앞선다. 파일 자체는 상위 10개로 잘라내지 않는다.
- 난이도에 따른 별도 순위 분리는 하지 않고 각 기록에 난이도를 표시한다. 새 기록은 `PLAYER: 321 [Easy] [Item]`처럼 난이도와 모드를 함께 표시한다. 이전 기록에는 존재하는 정보만 표시한다.
- 게임오버의 이름 입력 여부는 **그 게임 모드의 순위**로만 판단한다. 10개 미만이면 이름 입력을 받고, 10개 이상이면 10위보다 높은 점수만 받는다. 10위와 동점이면 기존 기록의 우선순위를 유지하여 이름 입력 없이 해당 모드 순위로 이동한다. 다른 모드나 모드 미상 기록은 이 판정에 영향을 주지 않는다.
- 저장 후에는 플레이한 모드 목록을 바로 열고 새 기록을 강조한다. 같은 이름·점수가 다른 모드나 난이도에도 있을 수 있으므로 네 필드 모두 일치하는 기록 중 가장 나중에 저장된 표시 행만 강조한다. 모드 전환 후에도 다른 기록에 강조가 옮겨 붙지 않는다.
- 긴 이름·정수 최대 점수·메타데이터로 줄이 길어져도 순위 내용에 접근할 수 있도록 목록에 스크롤을 제공한다.

## 검사 연결

| 검사 | 확인 범위 |
|---|---|
| `ScoreStoreModeTest` | 혼합 형식 저장/재조회, 모드 필터, 동점 안정 순서, 비정상 메타데이터, 끝 구분자 호환, 줄바꿈 보충, 전체 초기화와 재저장 |
| `ScoreStoreDifficultyTest` | 기존 난이도 기록과 2필드 파일의 호환 유지 |
| `ModeScoreUiTest` | 실제 필터 버튼/좌우키/Enter, 모드별 상위 10개, 메타데이터별 새 기록 강조, 해당 모드 10위 경계, 이름 입력 후 고정 정보 저장, 설정 메뉴 초기화 |
| `RefactoringRegressionTest` | 기존 55개 독립 회귀 유지. 게임이 쓰는 새 4필드 형식과 모드 표시의 기대값만 변경 |
| `DesktopSmoke` | 실제 JFrame의 저장·게임오버·해당 모드 순위 표시·전환·재조회, Classic 전체 순위와 독립적인 Item 진입, 화면 PNG |

`./gradlew build desktopSmoke packageRelease`로 전체 제품 coverage 70% 기준·회귀·실제 창·패키징을 함께 확인한다. 실제 운영체제에서 프로그램을 종료하고 다시 시작하는 물리 키 검증은 R2-07/TEST-06/RELEASE-04에서 이어간다. 이 작업은 신규 자체 아이템이나 전체 아이템 공급 검증을 포함하지 않는다.
