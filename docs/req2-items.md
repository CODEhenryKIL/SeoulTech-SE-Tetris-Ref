# R2-08·10·13 아이템 규칙과 공급 검증

`feat/req2-items-and-supply`는 모드별 기록 작업 `3a2620d` 위에서 이어서 진행한다. 원본 R2-01~07의 이력을 보존하고 신규 아이템, 기존 자체 아이템 C/B, 공급을 완성한다.

## 다섯 아이템

| 종류 | 모양·표시 | 고정 시 효과 | 효과 점수·삭제 행 누계 |
|---|---|---|---|
| 행 삭제 L | 무작위 일반 테트로미노의 점유 칸 한 곳에 L | L이 속한 행 전체 삭제 | 일반 완성 행과 합집합으로 계산 |
| 무게추 | 너비 4칸, 윗줄 가운데 2칸·아랫줄 4칸, 회색 O | 자신의 폭 아래 블록을 바닥까지 제거하고 바닥으로 이동 | 효과 점수 0, 제거 셀은 행 누계에 미포함 |
| 열 삭제 C | 무작위 일반 테트로미노의 점유 칸 한 곳에 C | C가 속한 열 전체 삭제 | 효과 점수 0, 열은 행 누계에 미포함 |
| 폭탄 B | 너비 3×높이 4, 첫 줄 가운데 1칸·나머지 세 줄 3칸, 갈색 B/O | 원래 외접 사각형에서 상하좌우 2칸까지 제거 | 효과 점수 0, 제거 셀은 행 누계에 미포함 |
| 교차 삭제 P | 너비 2×높이 2의 정사각형, 네 칸 모두 보라색 P (`#B04CFF`) | 원래 점유한 가로 2행과 세로 2열 전체 삭제 | 가로 2행만 삭제하면 300점·누계 +2, 열 추가 점수 0 |

C는 일반 블록처럼 이동·회전하며 표식 좌표도 함께 회전한다. B와 무게추는 회전하지 않고 회전 입력으로 위치도 바뀌지 않는다. P는 회전해도 모양과 위치가 같다. 일반 O 블록에는 P 효과가 없다. 무게추는 최초 접촉 후 좌우 이동이 잠긴다.

모든 효과는 바닥 또는 쌓인 블록에 고정될 때 한 번 적용한다. B의 범위는 보드 경계로 잘라내며 최대 7열×8행이고 자기 몸체도 제거한다. C는 표식 열만 지우므로 나머지 몸체 칸은 남는다. C/B 효과 이후에도 완성된 일반 행은 기존 규칙으로 삭제·계산한다. 실제 낙하 점수는 모든 아이템에서 기존 레벨 규칙대로 별도 유지한다.

### P 삭제 순서와 점수

1. P의 원래 두 행·두 열과 효과 적용 전 일반 완성 행을 기록한다.
2. 원래 두 열의 셀과 화면 문자를 함께 비운다. 열을 당겨 붙이지 않는다.
3. P의 두 행과 일반 완성 행의 합집합을 한 번만 삭제하고 위쪽 행을 내린다. 삭제 행보다 아래 행의 높이는 바뀌지 않는다.
4. 삭제 행마다 100, 200, 300… 순서로 점수를 더하고 행 누계·레벨·아이템 공급에 반영한다. 겹친 행은 중복 계산하지 않는다. 별도 완성 행 한 개가 더 있으면 총 3행·600점이다.

교차한 셀에는 중복 효과가 없고 세로 삭제에는 별도 점수·행 누계를 주지 않는다. 행·열 효과 애니메이션 중 이동·회전·낙하 입력은 무시한다. 정지·재개 의도는 유지하고 메뉴로 나가면 효과와 후속 블록 승계를 취소한다.

## 10줄 공급

- Item 모드에서 총 삭제 행의 10줄 경계를 넘을 때마다 지급 권리 1개를 얻는다. 한 번에 여러 경계를 넘으면 모두 보존한다.
- 고정 후 기존 미리보기는 그대로 현재 블록이 된다. 지급 권리가 있으면 새 미리보기에 아이템 하나를 공급하고 권리 하나를 소비한다. 남은 권리는 다음 고정 때 순차 공급한다.
- 예: 누계 9→21이면 권리 2개 중 하나를 즉시 새 미리보기에 공급하고 하나는 대기한다. 다음 고정에서는 줄을 지우지 않아도 두 번째 아이템이 미리보기에 나온다.
- 일반 이동·낙하 틱이나 삭제 강조 종료는 권리를 소비하거나 미리보기를 교체하지 않는다. 새 게임·초기화·게임오버·메뉴 종료에서는 대기 권리를 버린다.
- 아이템을 고를 때 L·무게추·C·B·P 각각 확률은 20%다. Classic은 같은 행 누계에서도 아이템을 공급하지 않는다.

## 검사와 산출물

| 검사 | 확인 범위 |
|---|---|
| `CrossBlockTest` | P 모양·문자·색상·회전 불변·독립 인스턴스 |
| `ColumnBlockTest` | 7종 × 4개 표식 위치 × 4회전 = 112개 상태의 C 좌표·점유 칸 일치 |
| `CrossItemAcceptanceTest` | 원래 행/열·벽/상단/바닥/쌓인 블록, 격자/문자 압축, 점수·승계, 네 팔레트 실제 렌더링 |
| `ColumnBombAcceptanceTest` | C/B 삭제 범위·경계·범위 밖 보존·몸체·점수/승계·회전·네 팔레트 렌더링 |
| `ItemSupplyAcceptanceTest` | 9→10·19→20·복수 경계·대기 지급·삭제 강조 종료·미리보기/현재 일치·Classic 제외·권리 초기화 |
| `ItemDistributionTest` | 실제 생성기를 seed 20261025로 100,000회 호출, 5종 각각 기대 확률 20% 대비 상대오차 5% 이내 |
| `Pr15BoardRegressionTest` | P를 포함한 효과 중 입력 차단·정지/재개·실제 메뉴 취소, 기존 L/무게추 회귀 |

분포 CSV는 `build/reports/req2/item-distribution.csv`, 팔레트별 PNG는 `build/reports/req2/rendering/`에 생성한다. 100,000회 및 오차 기준은 아이템 검증을 위해 정한 검사 기준이며 교수님 요구사항의 난이도 분포 검사와 구별한다. 픽셀 대비 자동 검사는 실제 화면에서의 수동 식별 평가를 대신하지 않는다.

```bash
./gradlew build desktopSmoke packageRelease
```

재현 가능한 자동 시나리오만 실행하려면 다음 명령을 사용한다. C/B/P를 정해진 보드 상태에서 실제 고정 처리에 통과시키고, `desktopSmoke`는 실제 창에서 P와 미리보기·점수·공급 흐름을 합성 키 입력으로 확인한다.

```bash
./gradlew test --tests '*ColumnBombAcceptanceTest' --tests '*CrossItemAcceptanceTest' --tests '*ItemSupplyAcceptanceTest' desktopSmoke
```

대상 OS 수동 확인에서는 Item 모드에서 10줄 삭제 후 지급되는 L/O/C/B/P 문자를 관찰하고, C의 한 열 삭제·B의 주변 제거·P의 두 행/열 삭제를 바닥과 쌓인 블록 위에서 각각 확인한다. P에는 실제 낙하 점수 외 기본 300점이 더해진다. 효과 도중 정지·재개/메뉴 복귀, Classic에서 아이템이 나오지 않음, 새 게임의 대기 지급 초기화도 확인한다. 네 팔레트에서 문자를 구분하는 평가는 사람의 확인 결과를 따로 기록한다.

기존 독립 회귀 55개와 제품 전체 line coverage 70% 기준을 유지한다. 최종 통합 버전의 PR 리뷰·병합, 실제 Windows 11 물리 키·패키지 실행·저장 후 종료/재실행, 평가 증빙은 R2-07/TEST-06/RELEASE-04에서 마무리한다.
